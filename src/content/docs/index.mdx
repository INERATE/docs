**acri** (`pyacri`) is a client-side capability resolution microkernel for AI agents. It eliminates prompt bloat by indexing 500+ MCP tools and selecting the exact top candidates in **40 microseconds** (0.040 ms).

```
┌─────────────────────────────────────────────────────────────┐
│                 THE ACRI AGENT MICROKERNEL                  │
│                                                             │
│  1. Capability Addressing         ──▶ compass.resolve()     │
│  2. In-Memory Registry            ──▶ corpus.index()        │
│  3. Model Abstraction Layer (HAL) ──▶ port.gemini / .openai │
│  4. Memory Management Unit (MMU)  ──▶ press.compact()       │
│  5. Process & Container Sandbox   ──▶ sandbox.sandboxed()   │
│  6. Real-Time Trace Visualizer    ──▶ acri studio (:8099)   │
└─────────────────────────────────────────────────────────────┘
```

## Why acri?

When building tool-calling AI agents, developers often dump 50 to 500 tool schemas directly into the LLM system prompt. This causes **three critical problems**:

1. **Context Window Bloat & Cost:** 100 tools consume ~15,000 tokens on *every single turn*.
2. **Model Confusion & Hallucinations:** Live benchmark accuracy drops significantly because the model struggles to choose among hundreds of competing JSON schemas.
3. **Prefix-Cache Invalidation:** In-turn tool swapping breaks provider KV prompt caching.

acri solves this at the microkernel layer:

* **Instant Indexing:** BM25 lexical inverted index over tool names, descriptions, and parameters.
* **40µs Resolution:** Selects top-$k$ relevant tools before the LLM wire call.
* **Universal Provider Support:** Native zero-dependency ports for Google Gemini, Anthropic Claude (Vertex/Direct), OpenAI (Azure/Direct), xAI Grok (Azure/Direct), Meta Llama (Cloudflare), and local vLLM/Ollama.

## Quick Installation

```bash
pip install pyacri
```

```python
import acri

# Register your tools
corpus = acri.index(tools)

# Resolve top-5 relevant tools in 40 microseconds
resolved = acri.resolve("is PR 42 ready to merge?", corpus, k=5)
```
