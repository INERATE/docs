## How to Reproduce

Run the test suite locally with your own API keys:

```bash
# 1. Resolver latency benchmark:
python -m assay.latency

# 2. Recall@k evaluation:
python -m assay.recall

# 3. Live model accuracy on Gemini 2.5 Flash:
python -m assay.accuracy

# 4. 504-tool enterprise scale stress test:
python -m assay.scale
```

## The Claims Policy

This project makes no performance claim it cannot reproduce. No number appears in this repository unless an automated script in `assay/` generates it from public fixtures.
