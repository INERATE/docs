# Inerate Documentation

The documentation source for [docs.inerate.com](https://docs.inerate.com/), built with Astro and Starlight.

- [acri quickstart](https://docs.inerate.com/acri/quickstart/): begin using the capability resolver.
- [acri architecture](https://docs.inerate.com/acri/architecture/): understand the implementation.
- [Atelier documentation](https://docs.inerate.com/atelier/): explore the framework and engineering guidance.
- [Research paper](https://research.inerate.com/acri): read the research behind acri.
- [Inerate Forge](https://forge.inerate.com/): find project pages and implementation resources.

Site configuration lives in `astro.config.mjs`; documentation content lives in `src/content/docs`. The GitHub Actions workflow builds and deploys the documentation to GitHub Pages at its Cloudflare-proxied custom domain.

Visit [Inerate](https://inerate.com/) for the ecosystem overview or [Inerate Tools](https://tools.inerate.com/all-tools) for PDF, image, and document utilities.
